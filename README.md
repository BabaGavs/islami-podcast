# İslami Podcast - PWA

## 📱 Mobil Uygulama Olarak Kullanım

### Android:
1. Chrome'da siteyi açın
2. Menü (üç nokta) → "Ana ekrana ekle" → "Yükle"
3. Uygulama ana ekranınıza eklenecektir

### iOS:
1. Safari'de siteyi açın  
2. Paylaş butonu → "Ana Ekrana Ekle"
3. "Ekle" butonuna basın

## 🚀 Play Store'a Eklemek İçin Seçenekler

### Seçenek 1: PWA (En Kolay)
- ✅ Ücretsiz
- ✅ Kod değişikliği gerekmez
- ✅ Google Play Store'da listelenebilir
- ⏰ 1-2 gün içinde hazır

### Seçenek 2: React Native (Orta)
- 💰 $25 Play Store ücreti
- ⏰ 1-2 hafta geliştirme süresi
- ✅ Tam native özellikler

### Seçenek 3: WebView (Basit)
- 💰 $25 Play Store ücreti
- ⏰ 2-3 gün geliştirme süresi
- ✅ Mevcut web sitesini sarmalar

## 📋 Play Store için Gerekenler

1. **Google Play Developer Hesabı** ($25 tek seferlik)
2. **Uygulama İkonları** (512x512px, 192x192px)
3. **Ekran Görüntüleri** (Telefon ve tablet)
4. **Açıklama ve Gizlilik Politikası**

## 🔧 Hızlı PWA Kurulumu

1. Siteyi herkese açık host edin (GitHub Pages, Netlify, Vercel)
2. Android'de test edin
3. İkonları ekleyin (icon-192.png, icon-512.png)
4. Play Store Console'da PWA olarak yayınlayın
